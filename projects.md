# Projects

Code for most of my projects can be found on my [GitHub page](https://github.com/edeno). Here are some select projects I've worked on:

## Data infrastructure

:::{container} project-list
- **[Spyglass](https://github.com/LorenFrankLab/spyglass)** — reproducible storage, analysis, and sharing of neurophysiology data, built on NWB and DataJoint. [Paper](https://doi.org/10.7554/eLife.108089.3) (co-first author)
:::

## Decoding hippocampal activity

:::{container} project-list
- **[Replay Trajectory Classification](https://github.com/Eden-Kramer-Lab/replay_trajectory_classification)** — decodes position from spiking and classifies replay as stationary, continuous, or fragmented. [Paper](https://doi.org/10.7554/eLife.64505)
- **[Non-Local Detector](https://github.com/LorenFrankLab/non_local_detector)** — hidden Markov models in JAX for detecting replay and decoding position from sorted or clusterless spikes.
- **[Track Linearization](https://github.com/LorenFrankLab/track_linearization)** — converts 2D position on a track into 1D position along it.
:::

## Signal processing

:::{container} project-list
- **[Spectral Connectivity](https://github.com/Eden-Kramer-Lab/spectral_connectivity)** — multitaper spectra and frequency-domain connectivity on the CPU or GPU. [Paper](https://doi.org/10.21105/joss.04840)
- **[Ripple Detection](https://github.com/Eden-Kramer-Lab/ripple_detection)** — sharp-wave ripple detection with several published detectors side by side.
:::

## Interactive visualization

:::{container} project-list
- **[RasterVis](https://github.com/NeurophysVis/RasterVis)** — browser tool for exploring spike rasters across many neurons. [Demo](https://neurophysvis.github.io/RasterVis/public/)
- **[SpectraVis](https://github.com/NeurophysVis/SpectraVis)** — browser tool for exploring functional brain networks over time and frequency. [Demo](https://neurophysvis.github.io/SpectraVis/public/)
:::
